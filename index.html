Python · OpenCV · NumPy · image models · 2026

AI texture remaster pipeline

Python tooling that upscales the remake's tiny DS textures with image models. Models like to "improve" a texture and change its design, so every output gets measured against numbers and against the original layout before I keep it. In one test I hid the real modern texture from the model. After three rounds of numeric feedback, its saturation was 0.01 off. Grout, stone and slab detail still didn't match.

Python · FastAPI · SGP4 · Docker · 2026

orbtrisk-cockpit: conjunction screening

A first-pass tool for finding close approaches between satellites. It propagates public TLEs with SGP4, flags pairs that come within 10 km, merges repeat alerts into one event, and grades how much to trust the data. It doesn't compute collision probability. TLE error is too big for that.

Stack: Python, FastAPI, SQLAlchemy 2, sgp4, Jinja2, pytest, Docker. Result: all 21 tests passed when I re-ran the suite on 28 Oct 2026. 17 commits, all mine, Feb–Oct 2026.
